# bin/

Vstupné body skriptov, volané ako `node <plugin>/bin/<name>.mjs` v koreni projektu (alebo s `--project <dir>`). Bez závislostí (P-034). Logika je v `scripts/`.

Cesty dát brainu a repa projektu skripty berú z mapy `scripts/layout.mjs` (`dataPath(<repo>, <logický názov>, ...)`, `dataRel` pre relatívne cesty zápisu, `LAYOUT` pre konštanty pri importe), nie literálom. Mapu vyberá verzia tvaru dát repa `dataLayoutVersion(<repo>)`: kľúč `data_layout` v `.brain/policy.json`, `policy.json` alebo `agentic/policy.json` (v tomto poradí), bez kľúča verzia 1.
