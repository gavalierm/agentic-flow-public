### P-065: Spoločný checkout iba zbiera (shared checkout collects only)

- **Typ:** zákaz
- **Problém:** Viac tém naraz menilo spoločný checkout kódového repa (vetva `dev`) a vznikol race: zmeny jednej témy sa miešali s druhou a commit či zlúčenie jednej témy bral súbory inej.
- **Pravidlo:**
  - Kód témy sa píše iba vo worktree témy (`<doména>/.worktrees/<repo>/<id>/`, vetva `topic/<id>`) alebo v klone témy.
  - Do pracovného stromu spoločného checkoutu vlákno nezapisuje (Write, Edit, zápis shellom) ani ho nemení gitom (`commit`, `merge`, `checkout`, `reset`, `rebase`, `stash` a pod.).
  - Spoločný checkout menia iba skripty workflow: `done --topic` (zlúčenie vetvy témy) a vydanie (`release.sh`).
- **Platí pre:** hlavného agenta a pracovníkov v každom kódovom repe, ktoré má worktree tém.
- **Detekcia:** zápis alebo git príkaz s cieľom v hlavnom checkoute repa, ktoré má `<doména>/.worktrees/<repo>/`, alebo repa v politike `topics.shared_checkouts`.
- **Vynútenie:** kód. PreToolUse (`hooks/pre-tool-use.mjs` `sharedCheckoutWrite`, `sharedCheckoutGit`) zamietne zápis súborovým nástrojom, zápis shellom a git príkaz meniaci checkout s pokynom: worktree témy, ktorú vlákno drží, inak `topic.mjs create <id> --class code --project <repo> --task "..."`. Čítanie, `scratch/`, ignorované cesty (`local/`) a `.git/` prechádzajú.
- **Príklad:** vlákno témy `x` upraví `hooks/stop.mjs` v `<doména>/agentic-flow` → zamietnuté, hook menuje `<doména>/.worktrees/agentic-flow/x/hooks/stop.mjs`. Správne: úprava vo worktree, commit vo vetve `topic/x`, zlúčenie `done --topic`.
- **Zdroj:** operátor 2026-11-13 (D-0038): race viacerých tém v spoločnom checkoute; práca iba vo worktree témy, `dev` je iba zberná vetva.
- **Výnimka:** povolená
