### P-071: Celá sada testov raz na stav kódu (full suite once per state of the code)

- **Typ:** povinnosť
- **Problém:** jedna zmena spúšťala celú sadu testov dva až trikrát: pracovník ju pustil po svojej úprave, vlákno témy pri každom commite a znova vydanie nad tým istým kódom; behy sa na stroji navyše prekrývali (2026-11-15).
- **Pravidlo:**
  - Celá sada testov beží raz na stav kódu.
  - Krok práce a podagent (pracovník, aj pri implementácii v kópii témy) spúšťajú iba testy, ktorých sa zmena týka (`node --test <súbor>`, `pytest <súbor>`, `npx jest <súbor>`, `go test ./<balík>`).
  - Celú sadu spúšťa vlákno témy raz pred zlúčením.
- **Platí pre:** pracovníka (subagent), krok práce a vlákno témy; hlavné vlákno a vlákno témy hook neobmedzuje.
- **Detekcia:** viac behov celej sady nad tým istým stavom kódu; pracovník s `npm test` alebo `node --test` bez súboru.
- **Vynútenie:** kód. Hook `pre-tool-use.mjs` (`fullSuiteCommand`) odmietne v subagentovi príkaz celej sady z politiky `harness.worker_full_test_commands` (regexy na každý úsek príkazu bez úvodných `VAR=hodnota`): `npm|pnpm|yarn [run] test`, `node --test` bez súboru, `npx vitest [run]` a `npx jest` bez súboru, `pytest` bez cesty, `go test ./...`. Pravidlá pracovníka z `delegate.mjs prepare --implement` a skill `delegate` (krok 2a) to hovoria jednou vetou. Test `tests/worker-named-tests.test.mjs`.
- **Príklad:** pracovník s `npm test` dostane „a worker does not run the full test suite (npm test): run only the tests the change touches …“; `node --test tests/x.test.mjs` prejde; vlákno témy spustí celú sadu raz pri `done --topic`.
- **Zdroj:** operátor 2026-11-15, agent-alice/D-0083.
- **Výnimka:** povolená
