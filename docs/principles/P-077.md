### P-077: Návrh sa vykresľuje ako HTML (a proposal is rendered as HTML, not a Markdown file)

- **Typ:** príkaz
- **Problém:** Agent predkladal návrhy (riešenie, plán, porovnanie možností, špecifikáciu) ako textový súbor `.md` alebo dlhý text odpovede. Operátor musel čítať rozsiahly text, aby našiel, čo sa navrhuje a o čom má rozhodnúť (operátor 2026-11-17: „návrhy musí agent vykresľovať cez HTML, nie ako textový súbor md, ktorý je rozsiahle čítanie“).
- **Pravidlo:**
  - Návrh aj report pre operátora (riešenie, plán, architektúra, porovnanie možností, špecifikácia, rešerš so záverom, report výsledku; aj keď operátor povie iba „report“) MUSÍ mať jednu z troch foriem, ktorú agent zvolí podľa obsahu: ASCII diagram v odpovedi (vojde na obrazovku), HTML stránka vo vlákne, alebo Artifact (stránka, ktorú operátor otvorí znova, pošle ďalej či sa dopĺňa). Nie súbor `.md` ani dlhý text odpovede. Návrh do 5 riadkov ostáva v texte odpovede (operátor 2026-11-18: „slovo report je buď ASCII diagram, alebo HTML report, alebo Artifact, rozhodnúť môže agent“).
  - Stránka je na prezretie, nie na čítanie: navrchu záver a čo má operátor rozhodnúť (alebo že rozhodovať nemusí, P-059); potom problém v 1–2 vetách, návrh vizuálne (schéma, tabuľka, porovnanie možností s odporúčanou prvou), dopady a riziká v bodoch. Bez opakovania kontextu, ktorý operátor pozná.
  - Jeden súbor bez externých zdrojov (CSS a SVG vnútri), čitateľný na úzkej obrazovke a vo svetlom aj tmavom režime.
  - Zobrazenie: v T3 súbor ukáž vo vlákne (`html_preview` s cestou, potom `html_render`); bez T3 daj do odpovede absolútnu cestu k súboru. Text odpovede má k návrhu 1–3 riadky a otázku, ak nejaká je.
  - Miesto: návrh, ktorý stojí za uchovanie, je výsledok témy (`save.mjs result navrh-<názov>.html`, P-067, P-052); pracovná verzia v pracovných súboroch. Súbor `.md` s návrhom nevzniká; dokument, ktorý má byť v repe ako Markdown (README, dokumentácia kódu), nie je návrh.
- **Platí pre:** manažéra témy, supervisora aj pracovníka, ktorý návrh pripravuje pre operátora.
- **Detekcia:** Návrh ako `navrh*.md`, `plan*.md`, `proposal*.md` v téme alebo pracovných súboroch; odpoveď s návrhom na viac ako jednu obrazovku textu.
- **Vynútenie:** pravidlo (jedna veta), skill `proposal` (štruktúra, forma, zobrazenie, uchovanie) a skill `save` (výsledok návrhu je `.html`).
- **Príklad:** Operátor chce vedieť, ako zabrániť nahraniu zastaraného exportu. Správne: stránka `navrh-cerstvy-export.html` so schémou toku (stiahni → uprav → nahraj, kontrola verzie), dvoma možnosťami s odporúčanou prvou a vetou „rozhodnúť: nič, nasadzujem prvú“; v odpovedi dva riadky. Nesprávne: `navrh-cerstvy-export.md` so 120 riadkami textu.
- **Zdroj:** operátor, 2026-11-17 („pridaj do workflow, že návrhy musí agent vykresľovať cez HTML, nie ako textový súbor md, ktorý je rozsiahle čítanie“).
- **Výnimka:** povolená
