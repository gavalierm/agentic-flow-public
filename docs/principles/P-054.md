### P-054: Zamietnutý príkaz (denied command)

- **Typ:** zákaz
- **Problém:** Agent dostal zamietnutie príkazu a tú istú zmenu urobil iným nástrojom (`python3` namiesto `sed -i`), bez zistenia príčiny a bez oznámenia. Zamietnutie môže byť rozhodnutie operátora alebo ochrana dát (brain); obídením ju agent vyradí.
- **Pravidlo:** Zamietnutie príkazu (pravidlo povolení harnessu, hook workflow) sa NESMIE obísť iným príkazom ani nástrojom s rovnakým účinkom. Agent uvedie príkaz a hlášku vo výsledku odpovede a pokračuje prácou, ktorá cieľ nepotrebuje. Smie zistiť príčinu (čítanie nastavení, neškodný pokus bez zmeny). Zamietnutie harnessom alebo operátorom je rozhodnutie operátora: ak ho práca potrebuje, otázka „povolíš …?“ dialógom `AskUserQuestion` (P-061). Zamietnutie hookom workflow menuje vlastnú cestu: tou sa ide. Ak nič iné neostáva, `Stav: hotovo` s krokom, ktorý ostal neurobený. Žiadosť o „pokyn na pokračovanie“ nie je otázka (P-059, P-061).
- **Platí pre:** hlavného agenta aj pracovníka (pracovník zamietnutie vráti v „Failures“).
- **Detekcia:** Po zamietnutí nasleduje príkaz s rovnakým cieľom a v odpovedi operátorovi zamietnutie chýba.
- **Vynútenie:** hook PreToolUse (`scripts/bypass.mjs`, od 2026-11-07). Zamietnutie hookom workflow sa zapíše do stavu vlákna, zamietnutie harnessom (pravidlo povolení, operátor povedal „nie“) sa číta z prepisu session. Ďalšie volanie v tom istom ťahu, ktoré siahne na tú istú cestu (alebo na priečinok, ktorý ju obsahuje) iným príkazom či nástrojom, hook zamietne. Po zamietnutom zápise je čítanie tej istej cesty povolené (zistenie príčiny), po zamietnutom čítaní nie. Rovnaké volanie znova rozhodne pôvodná kontrola. Najbližší prompt operátora začína nový ťah a blok zruší. Zamietnutie, ktoré menuje `save.mjs` ako cestu (P-013), nezamkne volanie `save.mjs`. Hromadné čítanie `docs/principles` blok nezapíše: jeden súbor princípu je cesta, ktorú stráž sama menuje (2026-11-08: zamietnuté `cat docs/principles/*` zamklo úpravu README a agent sa operátora pýtal na pokračovanie). Zápis do `.claude/settings*.json` (projekt aj používateľ) a git s `--no-verify` alebo so zmenou `core.hooksPath` vyžadujú potvrdenie operátora, lebo menia samotné stráženie.
- **Príklad:** `cd ../agentic-flow && sed -i … skills/<skill>/SKILL.md` zamietlo `Edit(skills/**)`: harness vyhodnotil relatívnu cestu voči priečinku session (brain), nie po `cd`. Správne: oznámiť, príčina, potom absolútna cesta. Nesprávne: prepísať to isté cez `python3`.
- **Zdroj:** operátor, 2026-11-01.
- **Výnimka:** nepovolená
